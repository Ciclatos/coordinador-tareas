# Referencias locales

Coloca aquí, únicamente para desarrollo local:

- `tarea-semana-5-ejemplo.pdf`: documento que sirve como referencia visual.
- `caratula-oficial.pdf`: plantilla PDF opcional para escribir datos sobre ella.
- `logo-umg.png`: logo institucional opcional.
- `caratula-plantilla.pages`: archivo fuente opcional de Apple Pages.

El contenido de esta carpeta está ignorado por Git porque puede contener nombres, carnés y trabajos estudiantiles. Nunca lo subas a un repositorio público. Ejecuta `pdftoppm -png references/tarea-semana-5-ejemplo.pdf tmp/pdfs/referencia` para inspeccionar las páginas localmente.
